## Cross-Renderer Ordering

Primary panel render order in `goPanel`: inject tables, inject legacy plots, KaTeX, Explore, Mermaid, Arquero, statistics, video, JSXGraph, then notes/animation (`_inline.v4.9.22.mjs:1076-1094`). Quiz rich content order is KaTeX, MathLive, Explore, Mermaid, Arquero, statistics, video, exercises, JSXGraph (`1532-1548`). Student export runtime order is KaTeX, MathLive, legacy plots/tables, Explore, Arquero, Mermaid, JSXGraph, statistics, video, exercises (`5422-5434`). Phase 2 adapters should encode and test these ordering differences before simplifying them.

## Renderer Adapter Contract Seeds

Every adapter should accept validated source data, a stable container, current theme/layout context, and an abort/cleanup handle. React components should not call `Plotly`, `JXG`, `mermaid`, `renderMathInElement`, or `mathVirtualKeyboard` directly.
