## Corruption Policy Observed

`LS.get` wraps `JSON.parse(localStorage.getItem(k))` and returns `null` on any error (`_inline.v4.9.22.mjs:599-603`). Student export `readJSON` catches and returns caller fallback (`4729-4735`). Migration should preserve forgiving reads but add typed validators around outputs before state use.

## Privacy Notes

All persistence is local to the browser. No backend is observed. Stored data can include authored lesson text, learner quiz answers, free responses, section notes, and test logs. The migrated app should keep local-first behavior and provide clear reset/clear controls for these data classes.
