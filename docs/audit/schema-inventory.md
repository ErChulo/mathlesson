## Unknown-Block Contract For Migration

1. Preserve original section HTML through import, editing, persistence, and export.
2. When structured parsing cannot classify a block, generate `html-fallback` with `metadata.originalType` and the original renderer/display source.
3. Do not make structured block records the only source of truth until round-trip tests prove no source loss.
4. Do not strip unknown properties from quiz questions or section objects unless a versioned migration and tests explicitly allow it.
5. Treat rendered Mermaid SVG as derived output, not canonical source.
